Cost

Provider-default runs with a known cost. Cost is a property of the run configuration and endpoint, not intrinsic to the model: provider routing, quantization, repeated retries, and the reasoning budget all change it. Measured cost is summed from per-request usage reported by the provider; reported cost is a dashboard total for runs made before usage capture, and covers only the completed run — retries and abandoned partial runs are not included.
